## 🚀 Project: Password Strength Checker

To apply today's concepts, I built a **Password Strength Checker**.

The program analyzes a password and classifies it as **Weak**, **Medium**, or **Strong** based on different security rules.

---

## ✨ Features

* Accepts a password from the user.
* Checks the password length.
* Detects uppercase letters.
* Detects lowercase letters.
* Detects digits.
* Detects special characters.
* Displays a detailed password analysis.
* Suggests improvements for weak and medium passwords.

---
