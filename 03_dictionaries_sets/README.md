## 🚀 Project: Programming Language Dictionary

To apply today's concepts, I built a **Programming Language Dictionary** using Python dictionaries and sets.

The program stores programming languages along with their primary use and allows users to manage the data interactively.

---

## ✨ Features

* Display all programming languages
* Search for a programming language
* Add a new programming language
* Update the purpose of an existing language
* Remove a programming language
* Display favourite programming languages
* Add a favourite language
* Remove a favourite language
* Display statistics
