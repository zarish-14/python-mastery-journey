# 📝 AI Prompt History Manager

A Python-based menu-driven application that allows users to save, search, view, count, and delete AI prompts using text file storage.

## 🚀 Features

* ➕ Add a new AI prompt
* 📖 View all saved prompts
* 🔍 Search prompts using keywords
* 📊 Count total saved prompts
* 🗑️ Delete prompt history
* 💾 Store prompts permanently in a text file

## 🛠️ Concepts Used

* Functions
* File Handling (File I/O)
* Loops
* Conditional Statements
* Strings
* Menu-Driven Programming

## ▶️ How It Works

1. Display a menu.
2. Select an option.
3. Perform the requested operation.
4. Return to the menu until the user exits.
