# 📊 Student Marks Analyzer

A beginner-friendly Python project that analyzes student marks using loops and conditional statements.

## 🚀 Features

- Display all student marks
- Calculate total marks
- Calculate average marks
- Find the highest marks and index
- Find the lowest marks and index
- Search for specific marks using Linear Search
- Count passed students
- Count failed students
- Display grades (A+, A, B, C, D, FAIL)

## 🛠️ Concepts Used

- Lists
- For Loop
- While Loop
- If-Else Statements
- Linear Search
- Break Statement
- Variables
- Arithmetic Operations

## ▶️ How to Run

```bash
python student_marks_analyzer.py
```

## 📚 Learning Outcome

This project helped me practice loops by solving a real-world problem without using Python's built-in functions like `sum()`, `max()`, or `min()`. It strengthened my understanding of iteration, searching, conditional logic, and algorithmic thinking.
