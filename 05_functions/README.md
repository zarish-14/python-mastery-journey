# 🤖 AI Prompt Quality Analyzer

A Python project that analyzes the quality of an AI prompt using functions and basic string analysis.

## 🚀 Features

- Accepts an AI prompt from the user
- Counts total characters
- Counts total words
- Counts uppercase letters
- Counts lowercase letters
- Counts digits
- Counts special characters
- Calculates a prompt quality score
- Rates the prompt (Excellent, Good, Average, Weak)
- Provides suggestions to improve the prompt

## 🛠️ Concepts Used

- Functions
- Parameters
- Return Values
- Strings
- Loops
- Conditional Statements
- Character Analysis
- Basic Algorithm Design
