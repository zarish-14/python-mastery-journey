# 💼 Freelance Proposal Tracker

A Python console-based application built using Object-Oriented Programming (OOP) concepts to help freelancers manage client proposals efficiently.

---

## 🚀 Features

- ➕ Add new freelance proposals
- 🔍 Search proposals by client name
- ❌ Delete proposals
- 🔄 Update proposal status
- 📊 View proposal statistics
- 📈 Count total proposals
- 👀 View all proposals
- 💡 Freelancing tips

---

## 🛠️ Concepts Used

- Python Classes & Objects
- Constructors
- Object Attributes
- Methods
- Static Methods
- Lists of Objects
- Loops
- Conditional Statements
- Menu-driven Programming
